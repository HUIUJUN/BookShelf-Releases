# PageRoom (BookShelf) Releases

PageRoom(구 BookShelf) Windows 설치 파일을 제공하는 공개 배포 전용 저장소입니다.

- 최신 정식 배포 파일은 [Releases](https://github.com/HUIUJUN/BookShelf-Releases/releases)에서 다운로드할 수 있습니다.
- Android 앱의 **앱 설정 → Windows 앱 다운로드**에서도 이 페이지로 연결됩니다.
- 이 저장소에는 앱 소스 코드, 개발/검증 도구, 인증 정보, 개인 책 또는 진단 로그를 올리지 않습니다.
- 검증을 완료한 정식 배포 바이너리와 해당 버전의 변경 내역·SHA-256 체크섬을 제공합니다.
