# BookShelf Downloads

BookShelf Windows 설치 파일을 제공하는 공개 배포 전용 저장소입니다.

- 설치 파일은 [Releases](https://github.com/HUIUJUN/BookShelf-Releases/releases)에서 제공합니다.
- Android 앱의 **앱 설정 → Windows 앱 다운로드**에서도 이 페이지를 열 수 있습니다.
- 이 저장소에는 앱 소스 코드, 개발/검증 도구, 인증 정보, 개인 책 또는 진단 로그를 올리지 않습니다.
- 검증을 완료한 배포물과 해당 버전의 변경 내용·SHA-256만 게시합니다.

현재 설치 파일은 아직 게시하지 않았습니다. 배포 검증과 게시가 완료되면 Releases에 표시됩니다.

다운로드 링크는 공유할 수 있으며, Android 앱 설치자를 인증하거나 접근을 제한하는 방식은 아닙니다.
